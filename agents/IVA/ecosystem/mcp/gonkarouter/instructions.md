# GonkaRouter MCP Tools

Use these tools to interact with models routed through GonkaRouter (https://api.gonkarouter.io/v1), including DeepSeek, MiniMax, and GLM.

## Tools
- `gonkarouter_list_models`: Lists available models.
- `gonkarouter_chat`: Executes full chat completions.
- `gonkarouter_ask`: Quick prompt tool for one-shot questions or tasks.
