# 40. Failure Taxonomy and Standard Recovery Codes

Use stable codes to avoid re-describing known failure patterns with long free-form logs. Codes must link to detailed, local diagnostics without exposing secrets.

| Code | Meaning | First recovery step | Escalation condition |
|---|---|---|---|
| `BROWSER_NOT_READY` | Browser driver is unavailable | Check service health and reconnect | Driver remains unavailable after bounded retry |
| `PAGE_IDENTITY_CHANGED` | Tab or origin differs from expected target | Stop and inspect URL/title | Identity cannot be grounded |
| `LOCATOR_NOT_FOUND` | Intended element was not located | Refresh local DOM and inspect labels | No accessible or visual target can be identified |
| `LOCATOR_AMBIGUOUS` | More than one candidate matches | Scope to form/dialog/region | Candidate remains ambiguous and consequential |
| `ACTION_TIMEOUT` | Action or transition exceeded budget | Reconcile whether action took effect | State cannot be reconciled |
| `RESPONSE_INCOMPLETE` | Output still streaming or never completed | Wait on completion detector with deadline | Deadline expires or output is malformed |
| `DUPLICATE_RISK` | Prior submission may already have happened | Inspect latest state before retry | Side effect status remains unknown |
| `AUTH_REQUIRED` | Authentication boundary encountered | Save checkpoint; use authorized sign-in | Authorization cannot be established |
| `RATE_LIMITED` | Website throttled requests | Honor wait guidance and back off | Repeated throttling prevents progress |
| `SANDBOX_UNAVAILABLE` | Approved isolation missing | Do not execute untrusted code; restore sandbox | No approved environment available |
| `DATA_STALE` | Source data out of date | Refresh from approved source | Freshness cannot be verified |
| `POSITION_MISMATCH` | Broker/simulator position differs from ledger | Halt new actions and reconcile | State is still unknown |
| `PERMISSION_DENIED` | Runtime rejected the requested access | Identify the missing specific permission | Only an authorized permission change can resolve it |
| `MEMORY_CONFLICT` | Durable records disagree | Compare source, date, and verification | Material fact cannot be verified |
| `TEST_REGRESSION` | A formerly passing test now fails | Isolate recent change and reproduce | No safe fix or acceptable disposition exists |
