Industrial design has been degraded into disposable glossy plastic and planned obsolescence. Werkstatt 08 machines structural instruments in solid brass, hardened tool steel, and raw phenolic resins. Every screw thread is standardized. Every assembly is user-repairable with a single 4mm hex key.

MASS INTEGRITY

A handheld tool must possess tactile mass. If a tool feels weightless, the user treats it as disposable garbage. Minimum casing thickness: 3.2mm cast bronze.

// PRINCIPLE 02

ZERO SOFTWARE LOCKS

No firmware dependencies. No cloud pairing handshakes. No Bluetooth telemetry for an object that turns, cuts, measures, or illuminates.

// PRINCIPLE 03

VISIBLE FASTENERS

Glue is cowardice. Ultrasonically welded plastic seams hide bad engineering. All Werkstatt housings expose metric M4 hex socket cap fasteners.
